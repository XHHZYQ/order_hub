## 2 通用约定

### 2.1 基础路径与版本

| 项 | 约定 |
| --- | --- |
| 基础路径 | `/api/v1` |
| 数据格式 | 请求与响应均为 `application/json; charset=utf-8`（文件上传/下载除外） |
| 版本策略 | 版本体现在路径中；本期固定 `v1` |
| 命名风格 | 资源名用复数、小写、连字符（如 `sku-mappings`） |

### 2.2 请求方法

| 方法 | 用途 |
| --- | --- |
| GET | 查询（列表、详情、统计） |
| POST | 新增、执行动作（如审核、同步、导入） |
| PUT | 全量更新 |
| PATCH | 局部更新、状态变更 |
| DELETE | 删除 |

### 2.3 统一响应体

所有接口（含失败）均返回统一结构，便于前端统一处理：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| code | int | 业务码，`0` 表示成功，非 0 表示失败 |
| message | string | 提示信息，失败时为失败原因 |
| data | object/array/null | 业务数据；分页时为分页对象 |

**分页响应体**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [],
    "total": 123,
    "page": 1,
    "page_size": 10
  }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| list | array | 当前页数据 |
| total | int | 满足条件的总记录数 |
| page | int | 当前页码（从 1 开始） |
| page_size | int | 每页条数 |

### 2.4 状态码与业务错误码

HTTP 状态码用于表达请求结果类别，业务错误码用于表达具体失败原因。

| HTTP 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功（含业务失败，由 `code` 区分） |
| 400 | 参数校验失败 |
| 401 | 未登录或登录失效 |
| 403 | 无功能权限或无数据权限 |
| 404 | 资源不存在 |
| 500 | 服务内部错误 |

| 业务码 | 含义 | 说明 |
| --- | --- | --- |
| 0 | 成功 | — |
| 1001 | 参数错误 | 参数缺失或格式非法 |
| 1002 | 未登录/登录失效 | 需重新登录 |
| 1003 | 无权限 | 功能权限或数据权限不足 |
| 1004 | 资源不存在 | — |
| 2001 | 唯一键冲突 | 编码/名称重复等 |
| 2002 | 状态不允许 | 当前状态不允许该操作 |
| 2003 | 库存不足 | 占用/发货时库存不足 |
| 2004 | 平台回写失败 | 回写平台失败，可重试 |
| 2005 | 对账期已封账 | 封账后不允许改动 |
| 3001 | 文件解析失败 | 账单/映射导入解析失败 |
| 5001 | 数据库错误 | 持久化失败 |
| 9999 | 未知错误 | 兜底 |

### 2.5 鉴权与请求头

| 请求头 | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是（登录接口除外） | `Bearer {token}` |
| `Content-Type` | 是（有请求体时） | `application/json` 或 `multipart/form-data` |
| `X-Request-Id` | 否 | 请求链路标识，便于排查 |

**鉴权流程**

1. 登录接口返回 Token，前端保存并在后续请求的 `Authorization` 头中携带；
2. 后端中间件校验登录状态，未登录返回 `1002`；
3. 接口层校验功能权限，按当前用户的数据权限过滤店铺范围。

### 2.6 分页与通用查询参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| page | int | 1 | 页码，从 1 开始 |
| page_size | int | 10 | 每页条数，**上限 100**，超过按 100 处理（防止单次请求过大失败） |

**通用筛选参数**（按接口支持的维度使用）

| 参数 | 说明 |
| --- | --- |
| keyword | 关键字（订单号、买家、商品名等模糊匹配） |
| shop_id / platform_code | 店铺、平台筛选 |
| status | 状态筛选（各模块状态不同） |
| start_time / end_time | 时间范围（按业务时间字段） |
| order_by / order_desc | 排序字段与方向 |

> 列表查询默认按业务时间倒序；`page_size` 上限统一由后端与前端双重限制为 100。

### 2.7 时间与金额格式

| 项 | 约定 |
| --- | --- |
| 时间 | 字符串 `YYYY-MM-dd hh:mm:ss`（前端展示口径）；接口入参与出参保持一致 |
| 时间范围 | `start_time`、`end_time` 精确到秒 |
| 金额 | 数值（Decimal），保留 2 位小数，单位元 |
| 数量 | 整数 |
